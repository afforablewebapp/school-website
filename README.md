# SRR EM School Website

This repository contains a modern multi-page school website for SRR EM School, inspired by premium educational site design.

## Pages
- `index.html` - Home page with hero carousel, features, testimonials, and admission callouts.
- `about.html` - School mission, vision, values, and location details.
- `contact.html` - Contact form, school information, and map embed.
- `admissions.html` - Admission enquiry form and application highlights.
- `academics.html` - Academic programs from Nursery to 7th Class.
- `faculty.html` - Faculty introductions and teaching strengths.
- `studentlife.html` - Student life, activities, and campus culture.
- `gallery.html` - Visual gallery with filter controls and lightbox preview.

## Assets
- Images are located in `assets/images/`.

## Styles and Scripts
- `style.css` contains the site design, responsive layout, and gallery styling.
- `script.js` includes page navigation highlighting, form validation, toast notifications, and gallery interactions.

## Run Locally
Open any HTML file in a browser to view the site locally.
